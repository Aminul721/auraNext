PHASE 4 — MONGODB DATA MODELS

A. Enquiry model Create a Mongoose Enquiry model with fields: - name:
required string, trimmed, length-limited - email: required valid email,
normalized lowercase - phone: optional string, length-limited - company:
optional string, length-limited - service: optional string or controlled
enum for the enquiry category - eventDate: optional valid date -
eventLocation: optional string - message: required string, trimmed,
length-limited - status: enum: new, contacted, in_progress, completed,
spam; default new - source: optional string, e.g. website - createdAt
and updatedAt timestamps

Add indexes for createdAt, status, and email where appropriate. Avoid
storing unnecessary personal data. Do not store passwords or secrets in
enquiry documents.

B. Admin model Create an Admin model with: - email: unique, normalized
lowercase - passwordHash: required; never store a plaintext password -
role: admin (allow future role expansion only if needed) - isActive:
boolean default true - lastLoginAt - timestamps

Use a unique index on email.
